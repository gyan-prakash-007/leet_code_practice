## 👋 What's in here

In this folder, you will find my C++ practice — following **Striver's A2Z DSA Sheet** step by step. That includes:

- Pattern printing and basic math/recursion warm-ups
- Sheet-wise problem solutions (arrays, strings, linked list, trees, graphs, DP, and so on)
- Any standard algorithm implementation I want on hand while practicing

C++ is where I actually sit with the STL, think about time/space complexity properly, and get closer to how interviewers expect this stuff to be written — not just "does it pass," but "is it clean and does it make sense."
